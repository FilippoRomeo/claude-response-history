# Claude Response History

A small macOS helper for Claude Code that provides stable, oldest-first assistant-response numbering and lets you copy previous responses by relative count, absolute number, list, or range.

## Commands

### `/ls-responses [N]`

Lists the last `N` substantive assistant responses from the current Claude Code session.

```text
/ls-responses
/ls-responses 25
```

The default is 10. Responses use stable oldest-first numbering within the filtered session history.

`/ls-responses` is optional. It is useful when you want to inspect absolute response numbers before copying them.

### `/copy-responses [selection]`

Copies assistant responses from the current session directly. Running `/ls-responses` first is not required.

Supported forms:

```text
/copy-responses
/copy-responses -1
/copy-responses -2
/copy-responses -3
/copy-responses -4
/copy-responses -10
/copy-responses 10
/copy-responses 2,3,4
/copy-responses 2-4
```

Semantics:

- no argument: copy the last response
- `-1`: copy the last response
- `-2` through `-10`: copy the last 2 through 10 responses, oldest to newest
- negative relative counts above 10 are rejected
- positive `N`: copy absolute response `#N`
- `n1,n2,n3`: copy those absolute responses in the requested order
- `n1-n2`: copy the inclusive absolute range from `n1` through `n2`
- absolute numbers may optionally start with `#`

If fewer responses exist than a requested relative count, all available responses are copied. Absolute selections that are malformed, reversed, zero, or out of range are rejected.

Multiple responses are separated by a blank line.

## Native Claude Code `/copy`

This project does not replace Claude Code's built-in `/copy`.

```text
/copy [N]
```

Claude Code's native `/copy` uses relative Nth-latest semantics. This project uses `/copy-responses` for stable oldest-first numbering plus explicit relative-count syntax using negative numbers.

## Requirements

- macOS
- Claude Code
- Python 3
- `pbcopy`
- Claude Code's default `~/.claude` user configuration directory

Validated with Claude Code 2.1.269.

## Installation

Clone the repository:

```sh
git clone https://github.com/FilippoRomeo/claude-response-history.git
cd claude-response-history
./install.sh
```

The installer creates:

```text
~/.claude/response-tools/bin/response_history.py
~/.claude/skills/ls-responses/SKILL.md
~/.claude/skills/copy-responses/SKILL.md
```

The installer refuses to overwrite an existing installation.

Start a new Claude Code session after installation.

## Quick test

Start Claude Code:

```sh
claude
```

Send several normal messages so there are multiple assistant responses, then try:

```text
/copy-responses
/copy-responses -1
/copy-responses -3
```

Use `/ls-responses 10` if you want to inspect absolute response numbers, then test:

```text
/copy-responses 2
/copy-responses 2,3,4
/copy-responses 2-4
```

The selected full response text should be copied to the macOS clipboard.

## How it works

The Python helper reads the local JSONL transcript belonging to the current Claude Code session and extracts substantive assistant text responses.

The two personal Skills pass `${CLAUDE_SESSION_ID}` and `$ARGUMENTS` directly to the helper.

Outputs generated by `/ls-responses`, `/copy-responses`, and native `/copy` are filtered from the numbered history.

## Privacy

Everything runs locally.

The helper:

- reads the current local Claude Code transcript
- sends selected response text to `pbcopy`

It does not require network access and does not modify project files or Claude Code transcript files.

Do not publish personal transcript files or other private Claude Code state under `~/.claude/projects/`.

## Safety

The Skills use:

```yaml
disable-model-invocation: true
```

This keeps them manually invokable by the user rather than autonomously invoked by the model.

It is not a filesystem security boundary and does not prevent Claude Code from editing unrelated files. Claude Code permissions remain separate.

## Compatibility

This implementation uses personal Skills under:

```text
~/.claude/skills/
```

The helper also depends on Claude Code's local transcript structure. Future Claude Code releases may therefore require parser updates.
